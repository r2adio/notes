#+title: Backend from first priciples

* high level understanding

* http protocol
  - establishing connection via http
  - http headers, its role and types
  - diff between simple and pre-flight request
  - http caching techniques
  - http/1.1 vs http/2.0 vs http/3.0
  - content neogtiation b/w client and server using diff headers
  - http persistent connections, and http compression techniques
  - security: SSL, TLS, HTTPS

* routing
  - types: static, dynamic, nested, hierarchical, catchall, wildcard, regex based routes
  - api versioning, best way to depricate a route
  - route grouping, and how it helps with versioning, permissions, shared middleware
  - securing routes, and optimize route matching performance

* serialization and deserialization
  - its need, and how it helps with interoperability standard
  - which format to choose: text (json/xml) vs binary (protobuf)

* authentication and authorization
  - types: statefull, stateless authentication
  - deep dive: oAuth protocol, OpenID Connect
  - best practices in security
  - audit logging: recording authentication authorization events for audits
  - monitoring failed attempts, and privilege escalation and access to sensitive resources
  - avoiding timing attacks

* validation and transformation
  - types: syntactic, semantic, type validation
  - need of client-side and server-side validation
  - transformation -> type-casting, date formats, normalization, sanitization

* middlewares
  - what and when to use middlewares
  - role of middleware in req cycle: pre-request and post-response
  - flow of middleware, and its order
  - middleware short-circuit req pipeline, by handling 404 errors
  - performance and scalability aspect of middlewares

* request context
  - meta data passed through application middlewares, controllers, services
  - its a request coped state, state is valid for that req.
  - tracking and logging info like req IDs, trace IDs
  - request specific data, custom data injected during req lifecycle (caching data, permission checks)

* handlers and controllers
  - the MVC pattern

* crud deep dive
  - crud operations mapping to http methods, and common api's

* best practices of rest
  - principle of designing api's around resources, and sticking to http semantics
  - best practices for filtering and pagination
  - design api's with openAPI specs
  - content neogtiation, capturing exceptions and providing meaningful msg

* databases
  - diff b/w relational and non-relational db
  - theoretical concepts: acid and cap theorem
  - best practices for db design: schema design and indexing
  - optimization methods: query optimization, caching, connection pooling
  - data integrity: constraints and validation, transactions and concurrency
  - how orm's work and when to use one, and its tradeoffs

* business logic layer (BLL)
  - design priciples like separation of concerns, single responsibility, open-close dep inversion
  - components of BLL: services, domain models (represents core entities)
  - business tools and business validation logic
  - best practices for designing service layer
  - propogating errors from service layer to presentation layer

* caching
  - need of caching, and how it differs from db persistence
  - types: in-memory, browser, db caching
  - diff caching strategies: cash aside, right through, right behind, right back, read through
  - diff cache eviction strategies: LRU, LFU, TTL, FIFO
  - need of caching invalidation: manual, time-to-live, event bash invalidation
  - levels of caching: L1 -> in-memory, L2 -> network distributed, Hierarchical caching -> L1+L2
